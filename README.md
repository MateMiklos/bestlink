# 📚 Bestlink Bookshop Management System

Bestlink is a modern replacement for our old Gardlink system — built using **Python + Flask**.  
It’s designed for local use in our bookshop to manage:
- Book inventory
- Sales and receipts
- Barcode scanner input (Honeywell compatible)
- Reporting and user management

---

## 🚀 Tech Stack

| Layer | Technology |
|-------|-------------|
| Backend | Python 3 + Flask |
| Database | SQLite (for local use) |
| Frontend | HTML + CSS + JS (Jinja2 templates) |
| Version Control | Git |
| Deployment | Local Windows server (via Flask) |

---

## 💻 Development Setup

### Requirements
- Python 3.10+
- Git
- Flask and dependencies (see `requirements.txt`)

### Installation

```bash
git clone <your_repo_url>
cd bestlink
pip install -r requirements.txt
python app.py
